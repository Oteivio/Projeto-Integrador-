# 🖼️ Diretório de Imagens (images/)

Este diretório serve como repositório central para guardar todos os arquivos de mídia (imagens, logotipos, capturas de tela do dashboard e diagramas explicativos) usados na documentação e no `README.md` principal do projeto.

---

## 🔗 Como Inserir Imagens no seu `README.md`

Para exibir uma imagem salva nesta pasta no corpo do seu arquivo Markdown principal, utilize a seguinte sintaxe padrão:

```markdown
![Texto Alternativo da Imagem](images/nome_do_arquivo.png)
```

### 💡 Recomendações Importantes:

1. **Formatos de Mídia:** Prefira salvar as imagens nos formatos `.png` (para capturas de tela e interfaces, pois preservam a nitidez dos textos) ou `.jpg` (para fotos genéricas de veículos ou planos de fundo).
2. **Resolução:** Tente reduzir o tamanho físico das imagens utilizando compressores online antes de salvá-las, mantendo-as abaixo de 1MB por imagem para evitar que o repositório fique muito pesado.
3. **Nomenclatura Limpa:** Utilize letras minúsculas e substitua espaços em branco por traços ou sublinhados nos nomes dos arquivos (ex: `dashboard_visao_geral.png` em vez de `Foto do dashboard 1.png`).
