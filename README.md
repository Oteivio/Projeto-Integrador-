🚗 Projeto Finalizado

O Projeto Integrador foi concluído com sucesso, utilizando técnicas de análise de dados para explorar informações sobre vendas globais da BMW e o impacto do preço do combustível no mercado automotivo.

🌐 Acesse o Dashboard

👉 Dashboard Streamlit

📊 Dataset Utilizado

A base de dados utilizada no projeto foi:

👉 BMW Global Automotive Sales Dataset (Kaggle)

O dataset contém informações relacionadas às vendas globais da BMW, incluindo dados de modelos, regiões, preços e desempenho de vendas.

🎯 Objetivo do Projeto

O principal objetivo da análise foi compreender:

O impacto do preço do combustível na formação do preço dos veículos
A influência nos custos de produção e transporte
A relação entre preço final e margem de lucro
O comportamento das vendas em diferentes cenários
🧠 Tipos de Análise Aplicadas
📌 Análise Descritiva
Exploração geral dos dados
Identificação de padrões e tendências
Comparação entre regiões, modelos e períodos
📌 Análise Preditiva
Aplicação de modelos para previsão de tendências
Estimativa de comportamento das vendas
Avaliação do impacto do combustível nos resultados futuros
📌 Análise Prescritiva
Geração de insights estratégicos
Apoio à tomada de decisão
Recomendações baseadas nos dados analisados

📌 Conclusão

O projeto permitiu analisar como fatores econômicos, especialmente o preço do combustível, podem impactar diretamente o setor automotivo, influenciando preços, vendas e margens de lucro.

Além disso, o desenvolvimento do dashboard possibilitou transformar os dados em informações visuais e interativas, facilitando a interpretação dos resultados e a geração de insights estratégicos.
