# 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de analisar o impacto do preço do combustível no mercado automotivo utilizando uma base de dados de vendas globais da BMW.

A proposta do projeto consiste em compreender como fatores econômicos podem influenciar:

* ⛽ Custos de transporte
* 🏭 Custos de produção
* 💰 Formação do preço final dos veículos
* 📈 Margem de lucro
* 🚘 Volume de vendas

---

# 📊 Dataset Utilizado

Base de dados utilizada:

🔗 [https://www.kaggle.com/datasets/dmahajanbe23/bmw-global-automotive-sales](https://www.kaggle.com/datasets/dmahajanbe23/bmw-global-automotive-sales)

O dataset contém informações relacionadas às vendas globais da BMW, permitindo realizar análises estatísticas, comparativas e preditivas.
